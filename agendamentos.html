⚙️ Configuração do Supabase

Para usar esta aplicação com múltiplos usuários, você precisa configurar um banco de dados Supabase.

1. Criar Tabela no Supabase:

Execute este SQL no seu projeto Supabase:

CREATE TABLE agendamentos ( id uuid PRIMARY KEY DEFAULT gen_random_uuid(), rede TEXT NOT NULL, dt_pedido DATE, lead_time INTEGER, cd TEXT, data_sap DATE, data_faturamento DATE, nf TEXT, num_pedido TEXT, data_solicitacao DATE, data_agendamento DATE, data_reagendamento DATE, data_expedicao DATE, transportadora TEXT, status TEXT, data_entrega DATE, observacao TEXT, criado_em TIMESTAMP DEFAULT NOW(), criado_por TEXT, atualizado_em TIMESTAMP DEFAULT NOW(), UNIQUE(nf, rede) ); CREATE INDEX idx_rede ON agendamentos(rede); CREATE INDEX idx_nf ON agendamentos(nf); CREATE INDEX idx_num_pedido ON agendamentos(num_pedido);
